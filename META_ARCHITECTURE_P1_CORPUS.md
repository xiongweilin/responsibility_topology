### EXO-1 — software deployment drift

> A component was tested successfully against a fixed interface and test suite. The code and proof artifacts did not change, but the production environment later changed in a way that may invalidate the old test conclusion for the intended use. What evidence should trigger another validation run, and what can remain unchanged?

### EXO-2 — DNSSEC parent/child rollover

> A child zone changes key material while a parent publishes delegation data used by many validators. Multiple providers may be involved, and stale or inconsistent parent data can break validation. Which party can settle the published state, which checks must be repeated, and when can dependent operators safely continue using it?

### EXO-3 — RPKI relying-party divergence

> Several relying parties fetch signed routing data from shared repositories but validate, cache, and apply routing policy locally. A source object changes or expires. Does this create one common decision that all parties must revise, or only separate local validation and policy updates?

### EXO-4 — Web PKI selective distrust

> A browser vendor has evidence that certificates associated with a trust provider should no longer receive the same treatment, but the deployed client representation does not yet expose a reliable per-certificate discriminator that supports selective remediation. Blanket or staged distrust remains operationally available. What exactly has been shown, and what has not?

### EXO-5 — preserved evidentiary objection

> A trial court makes a definitive evidentiary ruling. A party has created the record needed to preserve an objection for later appeal, while the ruling still controls trial use. Does preservation itself change the ruling's operative status, or does it only preserve a later procedural path?

### EXO-6 — measurement process drift

> A measurement process that previously met a procedure shows evidence of drift or loss of control. Existing results may still have traceability records. Which old results remain usable for which purposes, what remediation is required, and what additional evidence is needed before continued use?

### EXO-7 — unsafe component after new finding

> A component previously passed maintenance requirements, but a later safety finding identifies an unsafe condition and prescribes corrective action. The historical maintenance record remains intact. What changes immediately, what evidence must be produced, and what is sufficient to return the component to service?

### EXO-8 — multi-party shared basis with local change

> Several organizations rely on the same bounded shared data object for coordinated decisions. One participant's local evidence or authority changes materially, no single participant can unilaterally settle whether the shared basis remains fit for everyone's continued use, and ignoring the local change may affect others. What additional coordination or evidence is actually required?
