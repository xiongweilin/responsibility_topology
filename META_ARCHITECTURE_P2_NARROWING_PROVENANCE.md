# Meta-Architecture Audit — P2 Historical Narrowing Provenance

Status: **PROVENANCE AUDIT COMPLETE FOR CURRENT RECORDED LINEAGE / NOT A COMPLETE INTELLECTUAL HISTORY**

This audit asks what historical narrowing actually did before any new architecture is preferred. It uses exactly five operational states:

```text
ELIMINATED
ABSORBED
BRACKETED
UNOWNED
UNKNOWN
```

No sixth status may be introduced inside this audit.

## 1. Operational semantics

### ELIMINATED

The tested formulation was killed by falsification, stronger prior art, or a native decomposition. A renamed revival is rejected unless new evidence changes the kill premise.

### ABSORBED

The phenomenon remains real, but an ordinary/domain-native representation preserves the frozen material facts without requiring a new generic object.

### BRACKETED

The question was deliberately excluded to obtain a tractable subproblem. The bracket must have a recoverable reason or reopen condition; dormancy does not turn it into elimination.

### UNOWNED

The problem remains intelligible and potentially important, but the current working architecture has no natural owner. This status does not authorize a new track.

### UNKNOWN

The record is insufficient to decide whether the item is independent, absorbed, bracketed, or a false separation.

## 2. Q_open narrowing provenance

The historical broad Q_open line mixed at least four distinguishable questions: evidence admission, challenge/review procedure, higher-order model or representation failure, and authorization to reopen or revise a governing structure.

### QO-P1 — unindexed object acceptance

Old shape:

```text
A_K(e)
```

Forward replacement:

```text
Admissible_K(item,use)
```

Verdict:

```text
ABSORBED
```

Reason: intended-use distinctions preserve the tested native facts in pharmacovigilance and EPA cases without a new generic relation.

### QO-P2 — review implies challenge standing

Old shortcut:

```text
review / preserved challenge
-> generic ChallengeStanding
```

Verdict:

```text
ELIMINATED
```

Reason: preregistered QO tests and the Rule 103 re-audit did not require a generic standing object after ordinary procedural state was represented.

### QO-P3 — reviewability implies closure loss

Old shortcut:

```text
reviewable / preserved / under investigation
-> closure qualification defeated
```

Verdict:

```text
ELIMINATED
```

Reason: native closure/finality consequences were not established by review vocabulary alone. The permanent firewall is `reviewability != closure qualification`.

### QO-P4 — Rule 103 preserved-error residual

Native phenomenon:

```text
preserved claim of error while the ruling remains operative
```

Verdict:

```text
ABSORBED
```

Reason: issue identity, record witness, preservation status, potential review path, operative ruling, and use restriction preserve the audited facts.

### QO-P5 — unique/minimal revision localization

Old positive direction:

```text
minimal reopen scope / unique narrowest scope / scope lattice
```

Verdict:

```text
ELIMINATED
```

for a generic unique-localization claim.

The weaker methodological statement

```text
scope bounding may precede causal localization
```

is retained without creating an object theory.

### QO-P6 — representation-inadequacy component

Broad question:

> Can evidence show that the available distinctions are insufficient for the task before the correct refinement is known?

Verdict:

```text
BRACKETED -> QX
```

Reason: QX deliberately isolates the representation/distinction-space subproblem and subjects it to separate prior-art and provenance tests. This does not mean QX inherited all of Q_open.

### QO-P7 — non-representational regime/reopen authorization

Broad remainder:

> When may a system move from a local failure claim to a justified claim that the governing evaluative structure itself should be reopened or revised?

Verdict:

```text
UNOWNED / UNKNOWN
```

Interpretation: the old generic `ChallengeStanding` / closure-defeater construction was eliminated, but that negative result does not prove that every possible higher-order revision question is absorbed. QX owns only a representation-inadequacy slice. No current generic owner is earned for the remainder.

This is the principal architecture-debt finding on the Q_open side.

## 3. Q_close narrowing provenance

The historical Q_close direction concerned multiple finite systems, heterogeneous representations, shared determinations, authority, and distributed discharge. QC is a narrower evidence-gated working track, not a proof that the entire multi-agent space reduces to one object.

### QC-P1 — agreement/consensus as the missing object

Broad candidates based on agreement, no final arbiter, or heterogeneous quorum structure.

Verdict:

```text
ABSORBED
```

Reason: Byzantine/FBA/heterogeneous-quorum, judgment aggregation, belief merging, and semantic-mediation neighbors already cover broad agreement and heterogeneous-coordination phenomena.

### QC-P2 — same/shared object implies shared determination

Shortcut:

```text
shared source object / shared signed data / same label
-> one common determination
```

Verdict:

```text
ELIMINATED
```

for the tested inference. RPKI is the explicit negative control.

### QC-P3 — shared bounded determination implies novel multi-party relation

Shortcut:

```text
bounded common basis + several participants + later change
-> novel shared relation
```

Verdict:

```text
ELIMINATED / ABSORBED
```

for the tested DNSSEC-style case because bounded parent-side authority and explicit consistency/revalidation ownership preserve the material facts.

### QC-P4 — provisional shared determination without a final arbiter

Narrow QC mother question.

Verdict:

```text
UNKNOWN
```

Reason: no source-backed positive residual currently survives the hardened evidence gate. The object is not earned, but the empirical possibility is not eliminated and search saturation is not established.

### QC-P5 — distributed discharge composition

Question:

> If several actors hold different evidence, authority, or update duties, when does their local work jointly discharge a shared obligation?

Verdict:

```text
BRACKETED / UNOWNED
```

Reason: current QC work stops earlier at existence of one bounded common determination plus reliance/current-change structure. It has not earned a general composition rule for distributed discharge. Ordinary assigned duties absorb many cases, but the broader composition question was not globally eliminated.

This is the principal architecture-debt finding on the Q_close side.

### QC-P6 — heterogeneous representation translation

Question:

> When do different local semantic representations preserve enough common content to support continued coordinated use?

Verdict:

```text
ABSORBED where ordinary semantic mediation suffices;
UNKNOWN otherwise.
```

No generic residual has been earned.

## 4. Narrowing map

The history is therefore not accurately represented by either linear story:

```text
Q_open -> QX
Q_close -> QC
```

as if the left-hand questions had simply been renamed.

The more accurate map is:

```text
Q_open
  -> ELIMINATED generic standing/closure shortcuts
  -> ABSORBED use/procedural phenomena
  -> BRACKETED representation slice -> QX
  -> UNOWNED/UNKNOWN non-representational higher-order remainder

Q_close
  -> ABSORBED consensus/merging/mediation neighbors
  -> ELIMINATED shared-object shortcuts
  -> QC evidence search for a narrow provisional-shared-determination residual
  -> BRACKETED/UNOWNED distributed-discharge composition
```

## 5. Architecture debt exposed by P2

P2 does **not** show that QX/QC is defective. It does show that the current pair is not entitled to be read as an exhaustive coordinate system.

Two specific residual families remain without a current generic owner:

```text
R-U1: non-representational higher-order reopen/revision authorization;
R-U2: distributed discharge composition after local evidence/authority changes.
```

Both remain below promotion threshold. Their status is:

```text
UNOWNED != new track
UNOWNED != novel phenomenon
UNOWNED != architecture defect by itself
```

They are inputs to P3/P5 competition only.

## 6. P2 kill test

A provenance status is useful only if it changes future behavior.

This five-state system does change behavior:

```text
ELIMINATED -> renamed revival rejected absent changed kill premise;
ABSORBED   -> use ordinary/native model first;
BRACKETED  -> preserve explicit reopen condition;
UNOWNED    -> retain without promotion;
UNKNOWN    -> acquire evidence / avoid architecture conclusions.
```

Therefore the status system survives its own P2 kill condition.
