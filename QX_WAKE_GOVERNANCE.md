# QX Wake Governance

Status: **DORMANT / OPEN, PRE-FORMAL**.

This file governs the only legal ways to wake the QX representation-inadequacy track after Candidate-A/B falsification and the QX-5 non-unification audit.

## 1. Default state

QX is not active research construction.

```text
QX: DORMANT / OPEN
Candidate A: FROZEN / mechanism-specific survivor only
Candidate B: ELIMINATED / archived negative result
Generic QX object: NOT EARNED
QX Lean: NO
```

No new predicate, theorem family, domain rescue cycle, or formal object is authorized by dormancy alone.

## 2. Legal wake condition

QX may wake only through:

```text
E-WAKE OR T-WAKE
```

These channels are independent.

### E-WAKE — empirical wake

Requires a new, mechanism-distinct, source-backed residual that survives the existing provenance firewalls.

It may not be obtained by adding a fourth case to the completed Candidate-A cycle, reusing post-refinement hindsight, redescribing ignored signals as absent distinctions, or redescribing measurement/calibration error as representation inadequacy.

A single new case does not automatically earn a generic object or Lean phase.

### T-WAKE — theoretical wake

Requires a representation-independent, non-definitional argument whose conclusion is not already ordinary observability, diagnosability, non-identifiability, task infeasibility, model-class rejection, or abstraction refinement.

The active elimination question is:

> Is there a genuine impossibility concerning a finite responsibility system's entitlement to certify that its own representation is the source of task failure, rather than merely an impossibility of distinguishing states, diagnosing a critical property, or satisfying a task under a fixed observation/model structure?

T-WAKE must preserve the four-level firewall:

```text
cannot distinguish states
!=
cannot diagnose a critical property
!=
cannot satisfy task T
!=
cannot certify that the current representation is the source of failure
```

The decisive provenance question is:

```text
Who possesses the ground distinction used to establish the impossibility?
```

If an external analyst already possesses a concrete hidden state space or correct finer decomposition and proves two states observationally equivalent, the result is analyst-side non-observability unless an additional system-accessible certificate is independently established.

T-WAKE verdicts are limited to:

```text
CLOSED
CANDIDATE
```

`CANDIDATE` still does not open Lean.

## 3. Candidate A is not the T-WAKE object

Candidate A remains frozen under the provisional name:

```text
pre-refinement discriminator-unavailability witness
```

T-WAKE is not permission to continue collecting support for Candidate A. It asks whether a representation-independent argument exists that can wake QX without a second industry case.

## 4. Stop rule

If the strongest proposed theoretical residual is absorbed by observability / diagnosability / active diagnosis / non-identifiability / task infeasibility, record:

```text
T-WAKE: CLOSED
QX: DORMANT / OPEN
QX Lean: NO
```

Do not replace the failed argument with a nearby theorem merely to keep QX active.
