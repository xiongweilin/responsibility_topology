## Restart / escalation rule

A debt item may justify a new formal object only if ordinary/native decomposition cannot express the relevant responsibility fact without loss.

When a candidate object appears, the first question is:

> **Can this be eliminated by a better representation of the existing domain vocabulary?**

Only a negative answer earned from evidence can reopen the formal gate.
