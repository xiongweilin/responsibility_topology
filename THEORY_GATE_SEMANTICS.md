# Theory-Gate Semantics

Status: **REPOSITORY-LEVEL GOVERNANCE CLARIFICATION / NO RESEARCH-STATE CHANGE**.

Formalization: **NO**.

Authoritative state remains `RESEARCH_STATE.md`.

This file clarifies the meaning of the repository's current `TheoryGate: CLOSED` language.

## 1. The gate is a promotion/construction gate

For QX and QC, `TheoryGate: CLOSED` means:

```text
current evidence does not authorize
promotion of a new generic positive object,
expansion of a corresponding theorem surface,
or opening Lean formalization for that object.
```

It does **not** mean that theoretical inquiry itself is closed.

Permanent firewall:

```text
NoTheoryPromotionEntitlement
!=
NoTheoreticalInquiryEntitlement
```

## 2. Activities that remain admissible

The current freeze does not prohibit:

```text
theoretical criticism;
prior-art absorption audits;
conditional analysis;
countermodel analysis;
clarification of necessity/sufficiency conditions;
consideration of a materially new argument;
analysis triggered by new independently strong evidence.
```

These activities may change the evidence/governance state only through the existing QX/QC admission or wake rules.

## 3. What remains unauthorized

Current evidence does not authorize, by itself:

```text
a generic InsufficiencyCertificate;
a generic ProvisionalSharedReliance object;
a new QX/QC theorem family selected mainly by conceptual elegance;
Lean formalization of QX or QC;
a claim that all possible theoretical mechanisms have been searched;
a claim that no future theory can be earned.
```

## 6. Approved wording

Prefer:

> **No current evidence-forced positive theory-construction step is authorized.**

or, more explicitly:

> **Current evidence does not authorize promotion of a new generic QX/QC object, theorem surface, or Lean formalization. Theoretical criticism, absorption, conditional analysis, and materially new arguments remain admissible.**

Avoid unqualified formulations such as:

```text
no legitimate theory work remains;
the theory space is exhausted;
there is no valid next theoretical inquiry;
no future theory can be earned.
```

## 7. No new track

This clarification creates none of:

```text
a new research track;
a new QX/QC object;
a new wake condition;
a new theorem schema;
a Lean module;
a claim that theory-search stopping has been solved.
```

It only prevents an invalid inference from:

```text
no current positive object is evidence-forced
```

to:

```text
no further theoretical inquiry is legitimate.
```
