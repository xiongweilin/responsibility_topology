## 2. Frozen mother problem

The problem kernel is:

> **Under what accountable conditions may evidence that does not already satisfy a regime's ordinary object-level acceptance relation nevertheless acquire standing to challenge that acceptance/closure boundary over a bounded scope, without turning every anomaly into regime-level reopening?**

Equivalent shorthand:

```text
standing-to-challenge-the-gate
```

This wording is intentionally narrower than:

```text
model inadequacy detection
assurance defeater handling
argument attack representation
ontology repair
framework replacement
```

---

## 3. Five frozen distinctions

The QO-1 problem kernel consists of five claims that are now treated as the research checkpoint.

### Q1 — Anomaly is not inadequacy evidence

```text
Anomaly != InadequacyEvidence
```

A failure signal may be caused by input error, observation error, implementation nonconformance, local decision error, stale dependency, bad repair, missing representation, admissibility problems, purpose mismatch, or regime inadequacy.

The anomaly does not identify which responsibility layer is at fault.

### Q2 — Inadequacy evidence is not reopen entitlement

```text
InadequacyEvidence != ReopenEntitlement
```

Evidence that implicates a regime boundary may still lack sufficient standing, materiality, scope justification, provenance, or reviewability to defeat closure.

No direct anomaly/inadequacy-to-reopen shortcut is assumed.

### Q3 — Challenge standing is not object acceptance

```text
ChallengeStanding != ObjectAcceptance
```

Let `A_K(e)` denote ordinary object-level acceptance/admissibility.

Let `S_K(e, scope)` denote challenge standing over a bounded scope.

The frozen relationship is:

```text
S_K is not definitionally subordinate to A_K.
```

Q_open permits:

```text
S_K(e, scope) and not A_K(e)
```

when the reason for ordinary rejection is itself part of the challenged boundary.

But no universal implication is assumed in either direction:

```text
A_K(e) -> S_K(e, scope)      [not assumed]
S_K(e, scope) -> A_K(e)      [not assumed]
```

The relations are role-distinct, not merely ordered by permissiveness.

### Q4 — Reopen entitlement is a bounded defeater of unqualified closure

```text
ReopenEntitled(K, e, scope)
->
not UnqualifiedClosure(K, scope)
```

This is the immediate consequence frozen at QO-1.

It does **not** imply:

```text
not CurrentOperation
shutdown
withdrawal of all authority
isolation
regime replacement
truth of the challenge
validated replacement
```

A reopened unresolved challenge can coexist with provisional continued operation when a separate risk/governance judgment allows it.

### Q5 — Correspondence/implementation failure is not regime inadequacy

```text
observation mismatch
!= regime inadequacy

checker rejection
!= regime inadequacy

implementation nonconformance
!= regime inadequacy

local repair failure
!= reopen entitlement
```

This claim inherits only a **methodological discipline** from Strict Level 6: technical failure should be localized before being promoted to a higher-order regime conclusion.

It does not inherit a cross-domain theorem from the runtime/Lean bridge.

## 4. Symmetric failure modes

The kernel is only meaningful if it controls two opposite pathologies.

### FalseReopen

```text
local anomaly
-> unjustified regime-level escalation
```

Typical failure:

> a lower-level explanation, repair, or containment remains adequate, but the system reopens representation, admissibility, purpose, or governance anyway.

### ClosureBlindness

```text
potentially material challenge
-> cannot receive standing
because the challenged gate is also the sole gate
for deciding whether challenges may be heard
```

Canonical circular pattern:

```text
not A_K(e)
+
all challenge standing requires A_K(e)
--------------------------------------
e cannot challenge A_K
```

Q_open is not a doctrine of maximal openness. The problem is to avoid both false reopen and self-sealing closure.

## 5. Scope boundary

The analytical strata remain useful:

```text
execution / instance
local decision / inference
dependency / qualification / repair
representation / vocabulary / admissibility
purpose / governing regime
```

They are **not** frozen as a universal total order.

Future semantics may require:

```text
partial order
overlapping scopes
incomparable scopes
parallel provisional review
```

Freeze:

```text
minimal escalation != unique localization
```

The surviving bounded-scope intuition is only:

> do not authorize a review scope broader than the current evidence and explicit meta-responsibility assumptions justify.

QO-1 does not establish that one unique minimal scope always exists.

---

## 6. Anchor and regress boundary

Q_open requires no metaphysically independent oracle.

When a challenge relies on an external or heterogeneous anchor, the allowed claim is only:

```text
the anchor is not generated solely by the challenged responsibility path
```

The anchor may itself be defeasible, institutional, empirical, procedural, or governed by another authority.

Similarly, challenge standing does not eliminate regress.

Any later theory must expose a finite stopping/meta boundary such as:

```text
appeal authority
independent observation channel
heterogeneous reviewers
constitutional/safety boundary
human/external review
other explicit trusted meta-boundary
```

This relocates responsibility; it does not create ultimate self-grounding.

## 8. Hard neighbor-collapse criterion

Q_open should be retired if later falsification shows that every motivating case can be faithfully represented by established neighboring methods **including** all of the following:

```text
who/what may instantiate the challenge;
why evidence rejected at ordinary object level may still be heard;
what bounded scope the challenge defeats;
why closure defeat is distinct from object acceptance;
why closure defeat is distinct from replacement;
how false reopen is controlled;
where regress/meta-authority stops.
```

It is not enough for an existing framework merely to represent “an attack on an attack.”

But if it already supplies the complete standing/entitlement responsibility as well, Q_open has no independent kernel.

## 9. QO-2 entry conditions

No QO-2 domain is frozen at this checkpoint.

The next phase is heterogeneous falsification, and domain selection must be informed by the prior-art attack rather than chosen for narrative convenience.

QO-2 should test three candidates:

### H1 — standing without acceptance

```text
exists e, scope:
  S_K(e, scope) and not A_K(e)
```

Question:

> Are there real responsibility settings in which this distinction is genuinely needed, rather than merely representable?

### H2 — closure defeater rather than ordinary revision trigger

Question:

> Does `ReopenEntitled` add a useful distinction as a bounded defeater of unqualified closure, or do established revision/defeater triggers already capture the full responsibility?

### H3 — bounded scope under underdetermination

Question:

> Can bounded-scope responsibility remain coherent when evidence does not uniquely identify the revision location and multiple scopes may be incomparable?

Each selected domain must actively search for all three counterexample types:

```text
ordinary anomaly that should NOT reopen

inadmissible challenge that SHOULD receive standing

apparently serious challenge that should STILL fail standing
```

A domain that only supplies successful reopen stories is weak evidence and should not count as a QO-2 validation case.
